マシン上のすべての CLI にフォルダを。

コーディングセッションをフォルダに分け、ブラウザで開き、tmux で生かし続ける。Claude Code, Grok, Gemini, Codex、または設定4行で足した CLI。セルフホストは無料。有料は自分で立てたくない人向け。

Claude Code · Grok · Gemini · Codex · Antigravity · OpenCode · Cursor · Cline · Shell

フォルダ、tmux、ブラウザ。

clique @ 127.0.0.1:3200 
$ git clone https://github.com/thejdubb02/clique.git
$ cd clique
$ python3 -m clique password
$ python3 -m clique

Python 3.11+ と tmux。それだけ。あとは http://127.0.0.1:3200 を開きます。

セルフホスト 永久無料。MIT。クローンして、自分のマシンで動かす。ループバックにだけバインドします。
セルフホストしたくない 有料は後から。セッションはあなたのマシンに残ります。こちらでシェルをホストすることはありません。
常駐 24 MB。 フレームワークなし、node_modules なし、ビルドなし。
わざとループバック。 パネルに届く人は、あなたの端末を持っています。
リングが状態。 回転＝作業中。点滅＝あなた待ち。なし＝アイドル。

CLI の追加は設定であり、コードではない。

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = ["--always-approve"]
color   = "#E8E8E8"

ページを再読み込み。追加にコード変更が要るなら、設計は失敗しています。

よくある質問

インターネットに出す必要はありますか？

いいえ。デフォルトはループバックだけです。別のマシンから使うならトンネルを。公開ネットに直接出さないでください。パネルに届く人は、あなたの端末を持っています。

料金は？

セルフホストは無料、MIT。自分で立てない版は後から有料になります。パネルはあなたのマシンで動きます。

必要なものは？

Python 3.11+ と tmux。それだけ。Node も Docker もアカウントも不要です。

コーディング CLI を足すには？

設定に4行。ページを再読み込み。コード変更が要るなら、設計は失敗しています。

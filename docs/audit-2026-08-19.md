# CLIque audit — 2026-08-19

Bugs and optimizations for Claude Code to review and fix. Verified against the tree on this date. Skip style nits. Each item is something that should actually change.

Suggested order: **1, 2, 3, 4, 5**, then **8, 9, 10, 11, 12, 13**, then phone/touch (6, 31), then optimizations A/B so the panel stays cheap with a lot of sessions.

Do not spend time on: CSRF on modern browsers with `SameSite=Lax` + Origin (looks sound); XSS in sidebar/tabs (`escapeHtml` + `cssColor` are in the right places); tmux argv injection (argv lists, `={mux}` exact targets); artifact path traversal (resolve-then-`inside`, magic-bytes on serve); custom CSS as injection (documented feature; CSP blocks scripts); webhook SSRF as a *remote* hole (write access is already a root shell).

## High

### 1. “Going back” days slider never saves

**Where:** `clique/web/app.js` ~3667–3674

**Wrong:** `#setHistoryDays` `oninput`/`onchange` are nested inside `#setHistorySidebar.onchange`. They only bind after someone toggles “List past conversations”. Until then the slider updates the label and never PATCHes `history_days`. Every toggle also re-binds, so handlers stack.

**Fix:** Close the sidebar handler after its `saveSettings` call. Wire the days slider at the same level as the other settings. Add a smoke check that `history_days` persists without toggling the checkbox first.

---

### 2. A typo in `clis.toml` 500s the whole panel

**Where:** `clique/registry.py` `types()` ~364–377

**Wrong:** The comment says a bad file keeps the last good registry. `parse()` / `tomllib.load` exceptions are not caught, so `_types` is never returned. `/api/state` (and anything else that calls `types()`) 500s until the file is fixed. Hot reload is the advertised way to add a CLI.

**Fix:** Catch `RegistryError` and `tomllib.TOMLDecodeError`. Keep the last good `_types`. Do **not** update `_mtime` on failure (or store a “bad mtime” so you retry only when the file changes again). Log the error. Add a test: valid registry, write broken TOML, `GET /api/state` still 200s.

---

### 3. `clique token create` can wipe tokens the server already knows

**Where:** `clique/tokens.py` `_verify` ~145–163 and `_write` ~99–109

**Wrong:** The CLI and the server are separate processes. Server reloads, then later writes `last_used` from its in-memory list. A mint in between is overwritten. Same race the other way: server write vs CLI write. The in-process `RLock` does not help. This is the documented “mint without a restart” path.

**Fix:** `fcntl.flock` around load+write in both processes. Before any `_write`, reload from disk under the lock. Better: stop persisting `last_used` from the request path (or write it to a sidecar). Add a test that mints from a second `TokenStore` on the same file during `verify()`.

`tokens.py` `_write` also has no `flush`/`fsync`. `store.py` already does this correctly — copy that pattern.

---

### 4. State file is not in `$CLIQUE_HOME`

**Where:** `clique/__main__.py:148`, `deploy/clique.service`

**Wrong:** README / SECURITY.md say state lives in `$CLIQUE_HOME` (`~/.clique`). Default is `ROOT/data/state.json`. After `pip install` that is under `site-packages` (lost on upgrade, often not writable). The systemd unit sets `CLIQUE_HOME` but never passes `--state`, so password/tokens/secret go to `~/.clique` and folders/drafts/settings go somewhere else.

**Fix:** Default `--state` to `HOME / "state.json"`. Keep `--state` for tests. If the old checkout path `data/state.json` exists and the new one does not, migrate once. Point the unit at the same place.

---

### 5. Session killed elsewhere leaks a reconnecting PTY

**Where:** `clique/web/app.js` `refresh()` ~386–388, `attach()` `ws.onclose` ~2698–2708, `closeTab()` ~2507

**Wrong:** Comment says keep the tab and drop the socket. Code drops the id from `openTabs` and does **not** dispose `terms`. `session(id)` is gone, so onclose does not treat it as “Session ended” and retries for up to 60 attempts. Tab vanishes, xterm+WS+tmux viewer stay.

**Fix:** For any open tab whose session disappeared, run the same teardown as `closeTab` (`closing = true`, `clearTimeout(entry.retry)`, close WS, dispose term, remove el). If `!known.alive` **or** `!known`, stop retrying.

---

### 6. Folder edit is hover/right-click only

**Where:** `clique/web/app.css` ~125–131, `app.js` `folderMenu` / `wireTouchMenus`

**Wrong:** Pencil is `visibility: hidden` until `:hover`. Hidden controls don’t take taps. Long-press is wired for `.session`, not folder heads. Breaks the phone rule in `CLAUDE.md`.

**Fix:** Show the pencil when `(hover: hover) and (pointer: fine)` is false. Long-press a folder head → `folderMenu`. Same for history-row context menus (those rows have no `data-id`, so long-press misses them).

---

### 7. Keystrokes vanish while “Reconnecting…”

**Where:** `clique/web/app.js` `send()` ~2714–2718

**Wrong:** Sends only if `readyState === 1`. During reconnect, xterm still accepts input. Nothing reaches tmux.

**Fix:** Queue outbound bytes while disconnected and flush on `onopen`, **or** ignore input and keep the overlay until connected. Don’t echo locally if it isn’t going anywhere.

---

### 8. Negative `Content-Length` hangs a worker

**Where:** `clique/app.py` `_body()` ~668–678

**Wrong:** Login rejects `length < 0`. The API path does `self.rfile.read(-1)`, which reads until EOF. One authed request parks a thread forever.

**Fix:** Treat `< 0` like oversize: 413 and close the connection. Never pass a non-positive size into `read` except the empty-body case.

## Medium

### 9. `PATCH /api/settings` returns `webhook_secret`

**Where:** `clique/app.py` `do_PATCH` ~1220, `clique/web/app.js` `saveSettings` ~3328

**Wrong:** GET `/api/state` redacts it (on purpose — a read-only token could forge signatures). PATCH returns the raw store. `saveSettings` assigns that response to `state.settings`, so any settings save puts the secret in JS and clears `webhook_secret_set` until the next poll. A write token can read the current secret by PATCHing a dummy key.

**Fix:** Return `redacted(updated)` from PATCH (same shape as `/api/state`). Keep smoke coverage that asserts `webhook_secret == ""` and `webhook_secret_set` on **both** GET state and PATCH settings.

---

### 10. Oversized / invalid JSON is treated as `{}`

**Where:** `clique/app.py` `_body()` ~664–680

**Wrong:** `Content-Length > MAX_BODY_BYTES` returns `{}` **without reading the body** and without closing the connection. Keep-alive then desyncs. Invalid JSON also becomes `{}`. `POST /api/sessions` with either then creates a default shell in `$HOME`. Login already does this right (413 + close).

**Fix:** 413 + `close_connection = True` when too large. 400 on invalid JSON. Never invent an empty object for a mutation. Consume exactly `Content-Length` bytes on parse failure.

---

### 11. Drafts have no size cap

**Where:** `clique/store.py` `update_session` ~438–454

**Wrong:** Snippets are capped at 8k, CSS at 40k. `draft` is stored as-is (up to the ~14 MB body limit) and replayed on every `/api/state` poll.

**Fix:** Cap drafts (e.g. 8–16k) in `update_session`. Same for `name`.

### 12. `notify_idle_seconds` does nothing

**Where:** `clique/store.py`, settings UI, `API.md` — never read by `working.py` or `noticeFinished`

**Wrong:** The slider saves a number. Busy/finished still uses hardcoded `WINDOW`/`SETTLE`/`STILL` / `BUSY_HOLD_MS`.

**Fix:** Either thread the setting into `working.busy` / the finished detector, or remove it from UI + `API.md` + defaults.

---

### 13. Store reads are not under the lock

**Where:** `clique/store.py`; callers like `Panel.sessions_view`, `Watcher.tick`

**Wrong:** Writes take `RLock`. Callers iterate `store.sessions` / read `store.settings` unlocked. A create/delete during a poll can raise `RuntimeError: list changed size during iteration`.

**Fix:** Snapshot helpers that copy under the lock. Stop exposing the live lists.

---

### 14. Orphan tmux sessions after a failed persist

**Where:** `clique/app.py` `create_session` ~340–356

**Wrong:** `tmux.create` then `store.add_session`. A crash or write failure in between leaves an `sm-*` session the sidebar cannot see. `adoptable()` only scans foreign sockets. `docs/next.md` already names this (“reconcile records against tmux both ways”).

**Fix:** On startup, next to `sweep_viewers`: list `sm-*` (not viewers) on `SOCKET`. Re-attach orphans into the store, or kill them and log the count. Optionally write the store row first and mark it live after create.

---

### 15. `auto_folder` prefix match is too loose

**Where:** `clique/store.py` `auto_folder` ~262–274

**Wrong:** `cwd.startswith(prefix)` makes `/root/platform` match `/root/platform-old`. Folder `match` also has no PATCH field and no UI, so auto-file only works if you edit `state.json` by hand.

**Fix:** Path-prefix match (`==` or `startswith(prefix + "/")` after normalize). Add `match` to `PATCH /api/folders/<id>` and a place in the folder menu to edit prefixes. Document it in `API.md`.

### 16. Prompt Enter / Start can double-fire

**Where:** `clique/web/app.js` `run()` ~2810, prompt `keydown` ~3805, new-session submit

**Wrong:** No `ev.repeat` guard, no in-flight lock. WS-down path `await`s `/send` before clearing the box. Held Enter or a second Start click duplicates.

**Fix:** Ignore `ev.repeat`. Set a sending flag; disable Run/Start until the request finishes. Clear the box first or reject a second flight.

### 17. Image paste swallowed with no session

**Where:** paste capture handler in `app.js`

**Wrong:** Image-only paste is `preventDefault`’d, then `pasteImages` returns if there is no `activeId`. Clipboard contents are eaten, no toast.

**Fix:** Only prevent default after a session is active (and preferably after a successful save). Otherwise let the event through / toast.

### 18. Draft/workspace flush only on `visibilitychange`

**Where:** `app.js` ~3817–3821

**Wrong:** Debounced draft (600ms) is flushed on `hidden` only. Phone tab discard / some WebViews are more reliable on `pagehide`.

**Fix:** Also `saveDraft(true)` / `saveWorkspace(true)` on `pagehide`.

### 19. API.md is wrong in ways `api_drift.py` cannot see

**Where:** `API.md` vs `app.py` / `app.js`

**Wrong (verified):**

- `GET /ws?session=<id>` — code and the panel use `?id=`
- `GET /api/state` `home` is documented twice and never sent
- Session `order` is documented on the state payload and not included
- `marker_default` lists `"dot"`; real values are `both|icon|color|none`
- “Text frames are keystrokes” — code is the opposite: **text = JSON control, binary = keystrokes**

**Fix:** Correct `API.md`. Optionally accept `session` as a WS query alias. Extend `api_drift.py` at least for the WS query param and the `home` field if you keep claiming it (or add `home` to `state()`).

### 20. `_static` containment is a string prefix; `PUBLIC_ASSETS` is dead

**Where:** `clique/app.py` `_static` ~911–913 vs `_is_public_asset` which uses `artifacts.inside`; `PUBLIC_ASSETS` ~532–544, ~599–610, ~788–789

**Wrong:** `str(target).startswith(str(WEB.resolve()))` matches a sibling like `web-extra`. `PUBLIC_ASSETS` (`/favicon.ico`, `/manifest.webmanifest`) is unused; `_is_public_asset` only allows `web/brand/`. Unauthenticated `/favicon.ico` returns the login HTML.

**Fix:** Use `artifacts.inside(target, WEB.resolve())`. Allow the two public files explicitly (or move them under `brand/`). Delete or honor `PUBLIC_ASSETS`. Smoke: anonymous GET of favicon and manifest returns real bytes, not login HTML.

---

### 21. Webhook / status SSRF is check-then-connect

**Where:** `clique/notify.py` `allowed()` + `post()`; `clique/services.py` `read()`

**Wrong:** Resolves, rejects `169.254.0.0/16`, then `urlopen` resolves again. A short-TTL name can flip to metadata. Redirects are blocked (good). Anyone who can set the URL already has a shell, so this is defense-in-depth, not a remote hole.

**Fix:** Resolve once, connect to that IP, set `Host` to the original name, re-check the peer. Same pin in `services.read`.

---

### 22. `X-Forwarded-Host` / `X-Forwarded-Proto` trusted unconditionally

**Where:** `clique/app.py` `_host_ok`, `_same_origin`, `_secure`

**Wrong:** Any client can send those headers. Fine behind a tunnel that overwrites them; wrong if someone binds to more than loopback or a proxy forwards them blindly. Combined with the suffix allowlist (`.ngrok.io`, `.ts.net`, …), a client-controlled `X-Forwarded-Host` can satisfy `host_allowed()` and skew Origin vs Host matching.

**Fix:** Only honor `X-Forwarded-*` when `CLIQUE_TRUST_PROXY=1` (or equivalent). Otherwise use `Host` only. Document that proxies must overwrite, not append, client `X-Forwarded-Host`.

---

### 23. Hard-coded Codeman paths and Linux-only helpers on a “macOS” package

**Where:** `clique/migrate.py` `/root/.codeman/...`; `tmux.descendants` `ps --ppid`; `sysinfo.py` `/proc`

**Wrong:** Adopt name/cwd enrichment is a no-op for anyone not on this box. `ps --ppid` is Linux; macOS is in the classifiers. Stats go to zero on Mac.

**Fix:** `Path.home() / ".codeman" / ...`. Darwin `ps` without `--ppid`, or document Linux-only and drop the macOS classifier.

### 34. Login error HTML is unescaped

**Where:** `clique/auth.py` `login_page`

Errors are hardcoded today. Escape anyway so a later caller cannot XSS the login page.

**Where:** `clique/registry.py`

Lock the mtime check + parse + assign (still validate fully before publish).

**Where:** `clique/wsproto.py` ~215–225

RFC 6455: continuation with no prior data frame must fail. If `opcode == OP_CONT` and `message_op is None`, `close(1002)` and return `None`. Same if a new TEXT/BINARY arrives while a fragment is open.

Paste and artifacts exist, with containment and magic-byte typing. Update the doc so the next review is not chasing a ghost. Note any remaining gap (e.g. no `Content-Disposition: attachment` — less critical for sniffed image types).

## Optimizations

### A. `state.json` is rewritten on every tab focus and draft keystroke

`touch_session` and draft `update_session` fsync the whole document (indent=2). Coalesce writes (dirty + ~1s timer), or split `last_seen` / `draft` into a sidecar.

### B. Sidebar is fully rebuilt every 3 seconds

`renderTree` does `tree.innerHTML = ""`. Scroll position is not saved (`scrollTop` never read). A long sidebar jumps to the top on every poll. Save/restore `scrollTop`, and only rebuild when the session/folder fingerprint changes.

### C. One poll can `capture-pane` the same session three times

`working.busy`, `attention.detect`, `attention.saying` each capture. Watcher calls `sessions_view()` again every 10s. Share one capture per `(mux, activity)` per tick. Skip saying/detect when `last_seen >= activity`.

### D. History discovery re-reads 160 KB per transcript

~285 conversations, 30s all-or-nothing cache. Per-file cache on `(path, mtime, size)`.

### E. Unbounded webhook POST threads

`notify.post` starts a thread per event. Single worker queue, coalesce by session id.

### F. `applySettings()` rewrites custom CSS every poll

Theme/xterm already use a stamp. Stamp the CSS slots the same way.

### G. Opening the workspace attaches every tab at once

`refresh().then` `Promise.all(want.tabs.map(openSession))`. That is one PTY+WS per tab. Attach only the active tab; attach others when selected (or when the tab bar is clicked). Closing a tab already tears the PTY down — starting them all on reload fights that design.

### H. Re-verify bearer/cookie many times per request

`_bearer` / `_cookie_authed` are properties; the WS path hits verify + mtime several times per upgrade. Cache per-request on `self` after first resolve.

### I. CSP `connect-src` allows any `ws:` / `wss:`

`'self'` already covers same-origin WS. Drop the wildcards (include `wss:` only if a real deploy needs cross-host sockets).

Self-host Grátis para sempre. MIT. Clone, rode na sua máquina, só escuta em loopback.
Não quer self-host Uma opção paga está a caminho. As sessões ficam numa máquina que você controla — a gente não hospeda um shell para você.
24 MB residentes. Sem framework, sem node_modules, sem build.
Loopback de propósito. Quem alcança o painel tem um terminal como você.
O anel é o status. Girando = trabalhando. Pulsando = esperando você. Nada = ocioso.

Acrescentar uma CLI é config, nunca código.

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = []
color   = "#E8E8E8"

Recarregue a página. Se acrescentar uma exigir mudança de código, o desenho falhou.

Perguntas

Preciso colocar na internet?

Não. Escuta só em loopback. Ponha um túnel se quiser de outra máquina. Não pendure na internet pública — quem alcança o painel tem um terminal como você.

Quanto custa?

Self-host é grátis para sempre, MIT. A opção paga é para quem não quer rodar o setup. O painel continua na sua máquina.

O que eu preciso?

Python 3.11+ e tmux. Só isso. Sem Node, sem Docker, sem conta.

Como acrescento outra CLI de código?

Quatro linhas na config. Recarregue a página. Se precisar mudar código, o desenho falhou.

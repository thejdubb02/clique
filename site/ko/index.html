머신 위 모든 CLI에 폴더를.

코딩 세션을 폴더로 나누고, 브라우저에서 열고, tmux로 살려 둡니다. Claude, Grok, Gemini, Codex, 또는 설정 네 줄로 더한 CLI. 셀프호스트는 무료. 유료는 직접 돌리기 싫은 사람을 위한 겁니다.

Claude Code · Grok · Gemini · Codex · OpenCode · Cursor · Cline · Shell

폴더, tmux, 브라우저.

clique @ 127.0.0.1:3200 
$ git clone https://github.com/thejdubb02/clique.git
$ cd clique
$ python3 -m clique password
$ python3 -m clique

Python 3.11+와 tmux. 그게 전부입니다. 그다음 http://127.0.0.1:3200을 여세요.

셀프호스트 영원히 무료. MIT. 클론해서 당신 머신에서 돌립니다. 루프백에만 바인드합니다.
셀프호스트하기 싫다면 유료는 나중에. 세션은 당신이 통제하는 머신에 남습니다. 셸을 대신 호스팅하지 않습니다.
상주 24 MB. 프레임워크 없음, node_modules 없음, 빌드 없음.
일부러 루프백. 패널에 닿는 사람은 당신의 터미널을 가집니다.
링이 상태입니다. 회전 = 작업 중. 깜빡임 = 당신 대기. 없음 = 유휴.

CLI를 더하는 일은 설정이지, 코드가 아닙니다.

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = []
color   = "#E8E8E8"

페이지를 새로고침하세요. 추가에 코드 변경이 필요하면 설계가 실패한 겁니다.

자주 묻는 질문

인터넷에 올려야 하나요?

아니요. 기본은 루프백만입니다. 다른 머신에서 쓰려면 터널을 쓰세요. 공인망에 그냥 걸지 마세요. 패널에 닿는 사람은 당신의 터미널을 가집니다.

비용은요?

셀프호스트는 무료, MIT. 직접 돌리지 않는 버전은 나중에 유료입니다. 패널은 당신 머신에서 돌아갑니다.

뭐가 필요한가요?

Python 3.11+와 tmux. 그게 전부입니다. Node도 Docker도 계정도 필요 없습니다.

코딩 CLI를 더하려면?

설정에 네 줄. 페이지를 새로고침. 코드 변경이 필요하면 설계가 실패한 겁니다.

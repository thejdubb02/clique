CLIque GitHub

A folder for every CLI on the box.

Coding sessions in a browser, kept alive in tmux. Claude, Grok, Gemini, Codex, or anything you add in four lines. You clone it. It binds loopback. There is no cloud.

On your machine 
git clone https://github.com/thejdubb02/clique.git
cd clique
python3 -m clique password
python3 -m clique

Then http://127.0.0.1:3200. Python 3.11+ and tmux. Nothing else.

  • 24 MB resident. No framework, no node_modules.
  • Loopback. Put a tunnel in front if you want. Don’t hang it on the public internet.
  • The ring around a CLI’s logo is the whole status language: spinning = working, pulsing = waiting on you, nothing = idle.

Adding a CLI is config, never code.

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = []
color   = "#E8E8E8"

Reload the page. If adding one ever needs a code change, the design has failed.

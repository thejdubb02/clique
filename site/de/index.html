Ein Ordner für jede CLI auf der Box.

Coding-Sessions in Ordnern, im Browser, am Leben gehalten in tmux. Claude Code, Grok, Gemini, Codex oder jede CLI in vier Zeilen. Self-Host ist kostenlos. Bezahlt ist für Leute, die es nicht selbst betreiben wollen.

Claude Code · Grok · Gemini · Codex · OpenCode · Cursor · Cline · Shell

Ordner, tmux, ein Browser.

clique @ 127.0.0.1:3200 
$ git clone https://github.com/thejdubb02/clique.git
$ cd clique
$ python3 -m clique password
$ python3 -m clique

Python 3.11+ und tmux. Sonst nichts. Dann http://127.0.0.1:3200 öffnen.

Self-Host Für immer kostenlos. MIT. Klonen, auf deiner Box laufen lassen, nur Loopback.
Kein Self-Host Bezahlt kommt später. Sessions bleiben auf einer Maschine, die du kontrollierst. Wir hosten keine Shell für dich.
24 MB resident. Kein Framework, kein node_modules, kein Build.
Loopback mit Absicht. Wer das Panel erreicht, hat ein Terminal als du.
Der Ring ist der Status. Dreht = arbeitet. Pulsiert = wartet auf dich. Nichts = idle.

Eine CLI hinzufügen ist Config, nie Code.

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = ["--always-approve"]
color   = "#E8E8E8"

Seite neu laden. Wenn das jemals eine Codeänderung braucht, ist das Design gescheitert.

Fragen

Muss ich es ins Internet hängen?

Nein. Es bindet nur Loopback. Setz einen Tunnel davor, wenn du von einer anderen Maschine willst. Nicht öffentlich hängen. Wer das Panel erreicht, hat ein Terminal als du.

Was kostet es?

Self-Host ist kostenlos, MIT. Später kostet die Version, die du nicht selbst aufsetzt. Das Panel läuft weiter auf deiner Maschine.

Was brauche ich?

Python 3.11+ und tmux. Sonst nichts. Kein Node, kein Docker, kein Konto.

Wie füge ich eine weitere Coding-CLI hinzu?

Vier Zeilen in der Config. Seite neu laden. Wenn das Code braucht, ist das Design gescheitert.

Your private clique of CLIs.

Folder-organised, CLI-agnostic coding sessions in a browser, kept alive in tmux. One panel for every agent on the box — Claude Code, Grok, Gemini, Codex, or anything you add in four lines of config.

Open the GitHub repo Quick start

A driver, not an IDE.

CLIque does not parse a vendor’s protocol, impersonate a model, or reimplement the tools you already have. It keeps a private tmux server, puts every CLI session in a folder you can actually find, and gives you a browser to jump between them.

If you run more than two coding agents at once, you already know the problem: terminals everywhere, no idea which one is waiting on you, a conversation you cannot get back to. This is the panel for that.

24 MB resident. No framework, no node_modules, no build step. A PTY and the Python standard library.

Run it on your box.

There is no cloud product. You clone it, set a password, and it binds loopback. Put a tunnel in front if you want it from another machine — do not hang it on the public internet. Anyone who reaches the panel has a terminal as the user that started it.

git clone https://github.com/thejdubb02/clique.git
cd clique
export CLIQUE_HOME="$HOME/.clique"
python3 -m clique password
python3 -m clique                 # http://127.0.0.1:3200

Needs Python 3.11+ and tmux. Nothing else.

What it does

Command palette
Ctrl/Cmd+K — sessions, commands, past conversations.
Folders
A tree. Drag-drop, rename, search, collapse to a rail.
Tabs that don’t kill
Closing a tab is not killing the session. tmux and the CLI keep running.
History
Every conversation your CLIs kept, filed by directory, one click to resume.
Workspace
Open tabs follow you to another device. Drafts too.
Status
A ring around the CLI’s own logo: working, waiting, idle. The logo is never recoloured.
API
Every action in the panel is an HTTP call. Bearer tokens, including read-only.
Security
scrypt password, Host and Origin checks, CSP nonces. See SECURITY.md on GitHub.

Adding a CLI is config, never code.

[cli.grok]
label   = "Grok CLI"
command = "grok"
args    = []
color   = "#6f42c1"

Reload the page. If adding one ever needs a code change, the design has failed.

Not built, on purpose.

Subagent visualisation, a respawn controller, multi-host, a Ralph loop. Those need to know which vendor is talking. This product does not.
